# Spalten-Mapping

Erkenne in der eingefügten Tabelle die folgenden Spalten (inkl. gängiger Synonyme). Rate nie —
fehlende Spalten werden als **Datenlücke** ausgewiesen.

| Zielspalte       | Synonyme (Beispiele)                         |
| ---------------- | -------------------------------------------- |
| Einheit          | WE, Wohnung, Objekt, Einheit-Nr.             |
| Kaltmiete        | Nettokaltmiete, Grundmiete, KM               |
| Fläche           | Wohnfläche, qm, m²                           |
| Vertragsbeginn   | Mietbeginn, Einzug, Beginn                   |
| Letzte Anpassung | Letzte Mieterhöhung, Stand, letzte Anpassung |
| Mietart          | Index, Staffel, frei, Vergleichsmiete        |

**Regel:** Fehlt „Letzte Anpassung" oder „Mietart", ist der betroffene Vertrag **nicht bewertbar**
→ Datenlücken-Fund. Niemals einen Wert annehmen.
